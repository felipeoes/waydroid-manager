# Vendored Wayland protocol definitions

Copied unmodified from upstream so the window proxy can translate object ids in
every message the Waydroid hwcomposer exchanges with the compositor:

- `wayland.xml` — https://gitlab.freedesktop.org/wayland/wayland (protocol/)
- all other files — https://gitlab.freedesktop.org/wayland/wayland-protocols
  (stable/, staging/, unstable/)
